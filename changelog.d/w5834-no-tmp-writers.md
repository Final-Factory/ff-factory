- **Runners and bench tickets keep out of /tmp (w5834):** on Linux every CI runner unit gets a second drop-in, `ff-runner-tmpdir.conf`: `TMPDIR` inside the worker root (`<runner folder>/_tmp`, or `<root>/runner-tmp/<unit>` for a runner outside it) and `DOTNET_EnableDiagnostics=0`, and an idle listener started without it is restarted once, so no more `clr-debug-pipe-*` and `dotnet-diagnostic-*` in `/tmp`. A bench ticket's status file goes in `<root>/tmp/bench-status` instead of the OS temp folder (`ff-bench-<pid>-<hex>`); a folder that cannot be made falls back to the OS temp folder with a warning and never refuses the ticket.
