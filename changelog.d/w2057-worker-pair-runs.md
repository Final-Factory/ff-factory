- **Workers file their own pair runs, once per pull request (w2057):** `request_pair` takes `pr` and `commit`; a filing for a PR whose pair run is open (one filed by hand included) joins it, and one for a PR and commit whose run already finished is answered with that result and files nothing. A finished pair run resumes every request it serves with its result, so a worker that filed nothing is told too. The dispatcher's `decide_work` refuses to mark a repeat, clears a mark with `pair_legs 0`, and closes a never-started repeat as done. A worker whose report waits on a pair run with none filed is told to file it. [docs/machines.md](docs/machines.md), "One pair run per pull request and commit".
