- The FFBox host's path watch now says which version runs: every install (`install.sh`, `--host-only` included) records the ff-factory commit it installed from and the install time, and the watch puts both in every status file it hands the portal (`"installed": {"commit", "at"}`). `portal_logs` source `path_health` and `system_status` show them, so an install can be confirmed within a minute instead of waiting for the watch to make a repair (w4777).
