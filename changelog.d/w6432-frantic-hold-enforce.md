- Lower-priority work no longer takes a game sandbox that higher-priority work is queued for (w6432). A released worker resuming, and a room or away move, yield to strictly higher queued game work there: urgent and frantic work that also lacks an agent seat on that computer, and a request whose start just failed there (for 10 minutes), count as well. A move goes to another computer with room, or waits. This enforces what #1481 only warned about; the journal line is `move: worker … takes no game sandbox on …` and the resume's Queued line names the work it yields to.
