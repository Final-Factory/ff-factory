- **Merge on green merges only the worker's own pull request (w5549):** `blocked_on` with `merge_on_green` reads the pull request from GitHub and refuses, saying why, one whose head is not the worker's sandbox branch, its request's own branch or a branch named for its request, or that comes from a fork; at the merge FF Factory reads it again and does not merge a head that changed branch or repository. `ff-pr merge` refuses a fork's pull request, and with `--pr` one that is not the checkout's branch.
