- **`/mcp` is tailnet-only** (w1865, asked by Lothsahn: "Please lockdown the older mcp tools on the tailnet"): `routeMcp` refuses a request that came through Tailscale Funnel (the `Tailscale-Funnel-Request` header, or a client address outside the tailnet) with 403 before the key is read, for every tool and the upload, so the older tools (sandboxes, agents, branches and the rest) and any tool added later can no longer be reached from the public internet. Tailnet callers are unchanged, unbound keys included. [docs/talk-to-your-orchestrator.md](docs/talk-to-your-orchestrator.md#safety).
