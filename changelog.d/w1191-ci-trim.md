- CI does the same checks in fewer hosted jobs and less time (w1191). The Playwright tests run in two jobs, one per browser engine, instead of three shards. Each job starts only its own projects' servers (9 server boots a run instead of 27) and installs only its own browser. Pull requests that touch only `docs/`, `changelog.d/`, a top-level `*.md`, `deploy/` or `.github/` skip the Playwright tests. The secret scan and the identity check share one job. The Pixel-sized Chrome project runs only the specs where a phone behaves differently: attachments, chat, composer, replies, scroll keeping, rotation, layout and the screenshots (37 tests instead of 116); the rest already ran on desktop Chromium and the iPhone. `E2E_PROJECTS` picks projects locally too.
