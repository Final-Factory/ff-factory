- **An unfocused, idle editor closed for a timed run or an idle Live view now really quits** (w1829). The save-and-quit asked `EditorApplication.Exit(0)` on the editor's next update, and an unfocused, idle editor may not update for minutes: on BEAST on 2026-10-24 slot1's editor took the quit at 03:06Z, its panel said "closed for a timed run" for the whole 2-minute turn, and it quit only at 03:15Z, 10 s after a build woke it. One still running 15 s after it took the quit is now asked again with the same checks and save, then `Exit(0)` inside the bridge's own call, which runs while the editor does not update. Still never killed. [docs/live-view.md](docs/live-view.md), "Idle editors close".
