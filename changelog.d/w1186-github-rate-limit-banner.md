- A GitHub rate limit no longer reads as a missing token permission (w1186). The token check recognises a 403 or 429 with `X-RateLimit-Remaining: 0` or a `Retry-After`, a "rate limit exceeded" message and a GraphQL `RATE_LIMITED` error, keeps the token's last known verdict, and raises a separate banner, "GitHub is rate limiting us", naming the token, the account and the reset time instead of "A GitHub token needs updating". It clears itself on the first good call after the reset. The CI-read check keeps its last measurement under a rate limit too.
