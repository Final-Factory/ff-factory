- **A person's work can run on another person's Claude pool** (w1717): Settings → Claude pool picks, per person, "Self" (the default, as before) or another person's pool; any operator may change anyone's, and a person's orchestrator can with `set_pool`. It moves the Claude token of that person's workers and standing agents (new requests and the ones they act on), never their GitHub token or their orchestrator; the picked pool keeps its own caps, reserve and stop line, and its work waits while it is held (docs/vault.md section 4, "Picking another person's pool").
