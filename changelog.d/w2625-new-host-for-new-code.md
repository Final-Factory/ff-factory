- **A worker restarted on new FF Factory code gets new tools too (w2625):** an agent host started before or during a daemon update kept serving the old worker tool list after the update: the w1166 restart stopped only its agent, and the next message reached the old host while it was closing, which started the agent again inside itself on the old code (w2618's worker on BEAST, 2026-10-30, sat 2 h without `list_ffbox_files`'s bug-thread listing from PR #773). A host now records its code and tool list in `host.json`; a message for a host whose agent has ended and whose code, tool list or credentials differ from the daemon's (or that recorded neither, from before this change) stops it and starts a new host, between turns only. A worker that ends a turn waiting for someone to restart its agent host or tools is told at once none is needed and started again on its machine's code; its system prompt says so, and the ledger's Stalled line says so. Needs the machines' daemons at this version. [docs/machines.md](docs/machines.md) "A restart on new code starts a new host".
