- The blocker watch's backstop sweep no longer clears a CI wait whose run at its head is still running (w3796). Since #928 (w3786) CI readings are kept per commit, but the sweep's "finished at" marks were still looked up by the bare pull request: a wait set before that deploy (no head) that finished left a mark nothing deleted, and every later wait on the same pull request was swept at once, looping its worker (w3753 on ffu#533, 2026-11-09). The marks are now kept per commit, dropped when nothing reads them, and a wait is swept only when its own reading has finished.
