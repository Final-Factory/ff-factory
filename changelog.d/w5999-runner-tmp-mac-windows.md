- **Mac and Windows runners keep out of the system temp folder (w5999):** as on Linux (w5834), each CI runner's temp folder is inside the worker root (`<runner folder>/_tmp`, or `<root>/runner-tmp/<runner folder>` for one outside it) with `DOTNET_EnableDiagnostics=0`: on macOS in the runner's LaunchAgent plist, on Windows in its `.env` (`TEMP`, `TMP`, `TMPDIR`). An idle listener started without it is restarted once (macOS `launchctl bootout` and `bootstrap`; Windows exit code 2, which `run.cmd` relaunches), and a runner that does not come back is started again by the daemon for up to a day.
