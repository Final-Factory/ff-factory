- **"Turn off" in Settings now turns every notification off on that device, not only Web Push** (w1660, lothsahn: "I silenced notifications but the webpage keeps notifying me with windows toast messages"). Turning push off cleared the device's subscription, and the page then showed the same notices itself as in-page notifications whenever the browser permission was still granted and the tab was in the background. "Off" is now a choice kept in localStorage that the page and the service worker both respect; the device's push subscription is dropped on the server (retried at the next load if the call failed) and a stale one is never re-registered while off. A browser that can do Web Push and has no subscription no longer notifies from the page at all; only a browser with no Web Push (the in-tab fallback) does, until its "Turn off". Settings says which of push, in this tab only, or off is in effect. Needs a portal deploy (`web/`). `e2e/settings.spec.ts`, `server/notifyDevice.test.ts`.
