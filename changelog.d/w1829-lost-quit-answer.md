- **An editor closed for a timed run that quits before its answer arrives now comes back after the run** (w1829). The MCP bridge sends its answer from another thread after the call, and a busy editor runs the queued quit at once, so the answer can be lost: on BEAST on 2026-10-24 slot5's editor quit cleanly at 05:54Z, 2 s after the save and quit; the daemon counted the lost answer as a skip, dropped its "closed for a timed run" mark, and nothing started it again when the run ended. An editor whose answer never came and whose process goes within 15 s now counts as closed. [docs/live-view.md](docs/live-view.md), "Idle editors close".
