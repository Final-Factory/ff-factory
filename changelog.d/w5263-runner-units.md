- **CI runner units recover by themselves (w5263, w5264):** on Linux the daemon gives each systemd user unit that runs a registered GitHub Actions runner a drop-in (`RestartSec=30s`, `StartLimitIntervalSec=0`, `OOMPolicy=continue`), so a full disk no longer ends a unit for good and an OOM kill fails only that job. Once a minute it also starts a failed unit again when the disk is above its floor, and restarts a listener stuck busy for 10 minutes with no job worker (never while a worker runs or a bench turn holds it paused). [docs/self-recovery.md](docs/self-recovery.md), "CI runner units recover by themselves".
