- **Moves stop bouncing a request (w5942):** a request that moved to another computer for room waits there; it does not move again within 15 min. A worker that has its conversation waits up to 15 min for a seat on its own computer before a fresh session takes its work. A computer whose daemon refused a start at its agent cap gets no moves until a start there goes through (at most 30 min). A message queued for a worker whose request went to another worker now goes to that worker instead of being dropped. Old workers whose work moved but which still run are reported (warn only).
