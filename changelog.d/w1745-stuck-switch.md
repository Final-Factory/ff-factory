- **A worker whose token ran out no longer stays on it** (w1745): a resume that reached an agent host started by an older daemon (taken back across the daemon update, with no record of its credentials) ran on the used-up token again; such a host now hands the message to a new host on the new token. The automatic compaction waits until the worker has moved instead of running, and failing, on the used-up token. A worker still idle on a used-up token after a limit stop is resumed again 10 minutes later, at most 3 times, instead of waiting for a message nothing sends.
