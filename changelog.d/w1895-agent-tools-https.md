- **The agent tools step fetches the marketplace over HTTPS only, and tries a failed run once more** (w1895, lothsahn: "m5: agent-tools step of machine updates fails every time"). Claude Code fetches a github marketplace over SSH where `ssh -T git@github.com` authenticates and over HTTPS elsewhere, falling back to the other on a failure. m5's ssh key is on no GitHub account, so each time its HTTPS fetch failed (2 of 14 rollouts on 2026-10-23, both lasting about Claude Code's 120 s git timeout) the SSH fallback failed too, and the rollout reported only "Please make sure you have the correct access rights". `registerAgents.sh` now runs with `CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1` and `CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=300000` on every machine (final-factory-agents is public; a failure names the real HTTPS error), and a run that fails without timing out runs once more (`server/agentTools.ts` `REGISTER_ENV`).
