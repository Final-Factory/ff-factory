- **Sandboxes share their LFS files with the clone** (w1576, asked by lothsahn): a new sandbox, and each clean sandbox when it is released, runs `git lfs dedup`, which re-creates its Git LFS files as block clones of the clone's LFS store on ReFS and APFS. That is 9.1 GB of each game worktree on LothDesktop (measured on slot2: 5,026 files in 9 s). The daemon log says what it shared, or why it skipped (a dirty worktree, a file system that cannot clone).
