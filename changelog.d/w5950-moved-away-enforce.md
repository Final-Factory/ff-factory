- **Old workers whose work moved can be stopped (w5950, off by default):** the owner's setting `movedAwayWorkers` "on" stops a worker whose request moved to another computer when its daemon comes back still running it, or skips its resume, once a started new worker holds every request it had; its sandbox's uncommitted work goes to a side branch and the new worker is told. "warn" (the default) only reports them, as before; "off" turns the check off. [docs/machines.md](docs/machines.md), the w5942 section.
