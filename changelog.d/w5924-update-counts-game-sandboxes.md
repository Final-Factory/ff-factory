- w5924: a machine's update no longer refuses because of its light agent folders. The portal's `/machine/whoami` lists only game sandboxes (the light folders are `lights`), so the installer's `--max-sandboxes` check counts game sandboxes only. Before this, it refused beast, biscuit and lothdesktop ("--max-sandboxes 5 is below the 12 sandboxes there (slot1…slot5, agent1…agent7)"). The installer also tells light folders apart by their ids (agentN) when a portal gives no `lights`. The reinstall's unpushed-work check now looks for clones in light folders too: at the folder itself or up to 3 levels down, the same scan the daemon runs before it deletes one.
