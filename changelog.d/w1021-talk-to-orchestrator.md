- **Talk to your own orchestrator from Claude Code or Claude Desktop** (w1021, asked by Ben): `/mcp` gains `orchestrator_send` (your message as your own turn, the reply when its turn ends, or what it said so far with a cursor), `orchestrator_inbox` (what you have not read, with an optional wait), `orchestrator_attach` and `PUT /mcp/upload` (files, as `att_` ids). Same session, history and memory as the web app, which shows what you sent from there with a "via Claude Code or Desktop (key)" tag. The four orchestrator tools and the upload refuse a request that came through Tailscale Funnel (the `Tailscale-Funnel-Request` header, or a client address outside the tailnet) and a key that is not bound to a login; `ask_orchestrator` and `orchestrator_transcript` now refuse Funnel too. A call that waits answers as an event stream with progress notices. Setup for Claude Code and Desktop: [docs/talk-to-your-orchestrator.md](docs/talk-to-your-orchestrator.md).
