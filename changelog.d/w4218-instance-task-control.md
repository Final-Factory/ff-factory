- **update-all no longer leaves an instance stopped when it cannot disable its task** (w4218, Ben: "https://beast.tailedfcad.ts.net/#/ is down can you bring it back up"). On 2026-11-14 at 22:34 UTC it drained and stopped the Lens Scout portal, then `Disable-ScheduledTask fflensscout-portal` was refused (the task was registered from an elevated shell, so Administrators own it and the user may only read it), and its recovery's `Enable-ScheduledTask` was refused too, so `Start-ScheduledTask` never ran. Now each pass first checks that this user can disable and enable the instance's task(s) (disable, then enable again at once) and skips one it cannot control, before any drain, saying why once; it is rolled once the task is registered again from a normal shell. `start` runs `Start-ScheduledTask` even when `Enable-ScheduledTask` is refused.
