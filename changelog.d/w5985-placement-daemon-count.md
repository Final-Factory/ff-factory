- **Placement can count agents as the daemon does (w5985, off by default):** the owner's setting `placementAgentCount` "on" makes placement count a machine's agents as its agent cap does (turns sent and not yet reported, and standing agents, included) and take the larger of that and the machine daemon's own count while it is under 45 s old, so work is no longer sent to a computer whose daemon will refuse it (beast was counted "2 of 6" while its daemon counted 6, 2026-11-26). It never stops an agent; "off" or null puts back the old count.
