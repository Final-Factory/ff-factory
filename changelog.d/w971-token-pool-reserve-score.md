- **Token pool (w971):** a vault Claude token that is also the dispatcher's credential or the host token, while it is inside that credential's reserve, is handed to no new worker, standing agent, ops worker or orchestrator while another token of the person has room (with no other room the orchestrator uses it as before and workers wait); running processes are never touched. The pool now picks the token with the highest score, its weekly % left per hour until the weekly reset scaled by the 5-hour room, instead of the soonest weekly reset; `system_status`, `fffctl vault list` and the accounts list show each token's score. [docs/vault.md](docs/vault.md) section 4.
