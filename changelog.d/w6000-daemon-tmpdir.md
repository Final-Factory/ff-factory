- **The daemon's own temp files move inside the worker root (w6000):** at its start the daemon points `TMPDIR`, `TEMP` and `TMP` at `<root>/tmp/daemon` on every OS, so its own `os.tmpdir()` writes and those of every git, gh, ssh, python or script it starts stay out of `/tmp`, `/var/folders` and `%LOCALAPPDATA%\Temp`. Switch: daemon.json `daemonTmpdir` (default on; `ops_worker machine_update daemon_tmpdir off`, `--daemon-tmpdir`, `-DaemonTmpdir` to turn it off). It only warns: no root, a folder it cannot make, or a root too long for Unix socket paths keeps the system temp. The clean-up, the browser reaper and Git Bash's `/tmp` keep reading the system temp (`FF_SYSTEM_TMPDIR`). Sandbox editors keep what `editorTmpdir` gives them. `ff-leftovers remove` no longer removes `runner-tmp` whole. A census test (`server/w6000SystemTemp.test.ts`) lists every place left that names the system temp, and why.
