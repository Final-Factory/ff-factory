- **The Dev Drive step no longer hangs silently** (w1993): each storage step says what it starts, has a time limit and says it is
  still working every 30 s; the installer shows those lines as they come. The partition is formatted before it gets its letter,
  so Windows' "You need to format the disk" prompt never appears, and a drive cut off mid-format is finished on the next run.
  A play-only timing machine makes no Dev Drive at all.
